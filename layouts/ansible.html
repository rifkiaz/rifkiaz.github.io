    Isi tiap server ikut berubah saat playbook jalan. Matikan satu server pakai tombolnya buat lihat UNREACHABLE.

    apa itu Ansible, playbook, dan idempotent?
    • Ansible mengatur banyak server sekaligus lewat SSH, tanpa agent. Cukup ada Python di server tujuan.
    • Inventory berisi daftar host dan grupnya. Playbook berisi play: "di grup ini, jalankan task-task ini". Tiap task memanggil satu modul, misal apt, template, atau service.
    • Hasil per host: ok (sudah sesuai, ga diubah), changed (diubah), failed (gagal, host itu berhenti di play ini), unreachable (ga bisa SSH), skipping (kondisi when ga terpenuhi).
    • Idempotent artinya dijalankan berkali-kali hasilnya sama. Modul seperti apt dan template cek dulu sebelum mengubah, jadi run kedua harusnya changed=0. Modul shell dan command ga tahu apa-apa soal kondisi server, jadi selalu changed, kecuali dikasih creates: atau changed_when: false.
    • Handler cuma jalan kalau ada task yang changed dan memanggilnya lewat notify, dan jalannya sekali di akhir play. Cocok buat restart service setelah config berubah.
    • --check menjalankan playbook tanpa mengubah apa pun, --diff menampilkan isi file yang bakal berubah, dan --limit membatasi host yang dikerjakan.
    • Modul apt cuma ada di keluarga Debian/Ubuntu. Buat server campuran, pakai modul package, atau pisahkan dengan when: ansible_os_family == "Debian".
