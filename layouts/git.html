    apa itu staging, branch, merge, rebase, dan reflog?
    • Tiga tempat di laptop. Working dir adalah file yang kamu edit. Staging (index) adalah isi commit berikutnya: git add menyalin file ke sana. git commit menyimpan isi staging jadi satu snapshot permanen di repo lokal. Jadi kamu bisa memilih perubahan mana yang masuk commit.
    • Branch cuma penunjuk. Branch adalah nama yang menunjuk ke satu commit, dan HEAD menunjuk ke branch yang sedang kamu pakai. Tiap commit baru menggeser branch itu maju. Bikin branch itu murah, ga ada file yang disalin.
    • Merge. Kalau branch tujuan belum maju, Git cukup menggeser penunjuknya (fast-forward). Kalau dua-duanya sudah maju, Git bikin merge commit dengan dua parent. Kalau baris yang sama diubah di dua sisi, Git berhenti dan menandai konflik pakai <<<<<<<, =======, dan >>>>>>>. Kamu yang memutuskan isinya, lalu git add dan commit.
    • Remote. origin adalah salinan repo di server, misalnya GitHub. git push mengirim commit kamu, git fetch mengambil commit orang lain ke origin/main, dan git pull = fetch lalu merge (atau rebase). Push ditolak kalau di remote ada commit yang belum kamu punya.
    • Rebase. Memindahkan commit-commit branch kamu supaya seolah dibuat di atas ujung branch lain. Riwayatnya jadi lurus, tapi commit-nya dibuat ulang dengan hash baru, jadi jangan rebase commit yang sudah dipakai orang lain.
    • Reset, revert, dan reflog. git reset memundurkan branch (--soft perubahan tetap di staging, --mixed di working dir, --hard dibuang). git revert membuat commit baru yang membatalkan commit lama, aman buat branch yang sudah di-push. Commit yang "hilang" karena reset masih bisa ditemukan di git reflog.
    • Stash. Menyimpan perubahan yang belum siap di-commit ke tempat sementara, supaya working dir bersih dan kamu bisa pindah branch. git stash pop mengembalikannya.

    Ini simulasi, bukan Git beneran. Repo, remote, dan teman satu timnya bohongan, dan perintahnya cuma sebagian. Hash commit-nya acak. Semua cuma ada di browser kamu dan ga disimpan di mana pun.
