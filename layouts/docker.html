    apa itu image, container, layer, dan volume?
    • Image itu cetakan: file sistem plus perintah default, dibangun dari Dockerfile. Container itu image yang lagi dijalankan. Satu image bisa jadi banyak container.
    • Tiap baris RUN, COPY, dan ADD bikin satu layer. Saat build ulang, Docker memakai ulang layer yang input-nya sama (CACHED). Begitu satu layer berubah, semua layer di bawahnya dibangun ulang. Makanya COPY requirements.txt dan pip install sebaiknya ditaruh sebelum COPY . ..
    • Container itu sekali pakai. Ubah kode lalu build ulang ga mengubah container yang sudah jalan. Kamu harus hapus dan bikin container baru dari image baru.
    • File yang ditulis di dalam container hilang saat container dihapus. Simpan data di volume (-v nama:/path) supaya tetap ada.
    • -p 8080:80 artinya port 8080 di laptop diteruskan ke port 80 di container. EXPOSE di Dockerfile cuma dokumentasi, ga membuka port apa pun.
    • Aplikasi di container harus listen di 0.0.0.0. Kalau cuma di 127.0.0.1, dia ga bisa diakses dari luar container walau port sudah di-publish.
    • Container di network buatan sendiri (termasuk yang dibikin Compose) bisa saling panggil pakai nama. Di network bridge bawaan, nama ga bisa di-resolve.
