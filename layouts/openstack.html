    Dashboard masih kosong karena kamu belum login. Di OpenStack, semua akses lewat Keystone: kamu login sebagai user, lalu dapat token untuk satu project.

    Tombol ini cuma mengetik perintah openstack server create ke terminal. Horizon juga begitu: semua klik jadi panggilan API.
    apa itu Keystone, Nova, Neutron, dan kawan-kawan?
    • Keystone mengurus login. File demo-openrc berisi alamat Keystone, user, dan project. Setelah di-source, perintah openstack minta token dulu, lalu token itu dipakai ke semua service lain. Semua resource milik satu project, dan tiap project punya quota.
    • Nova menjalankan server (instance) di compute node. Ukurannya dipilih dari flavor (vCPU, RAM, disk), isinya dari image yang disimpan Glance.
    • Neutron mengurus jaringan. Network dan subnet project kamu itu privat, misalnya 10.0.0.0/24. Supaya bisa keluar ke internet, subnet itu harus disambungkan ke router yang punya gateway ke network eksternal public.
    • Floating IP itu IP publik dari network public yang di-NAT oleh router ke IP privat server. Tanpa router yang tersambung, floating IP ga bisa dipasang.
    • Security group itu firewall per port server. Grup default cuma mengizinkan trafik dari sesama anggota grup, jadi SSH dari laptop bakal timeout sampai kamu menambah rule port 22.
    • Keypair disuntikkan ke server saat boot lewat cloud-init. Lupa --key-name waktu bikin server? Kuncinya ga bisa ditambah belakangan; bikin ulang servernya.
    • Cinder menyediakan volume (block storage) yang bisa dicopot dan dipasang ke server lain. Datanya tetap ada walau servernya dihapus.

    Ini simulasi, bukan OpenStack beneran. Cloud-nya bohongan, IP-nya pakai rentang contoh, waktunya dipercepat, dan perintahnya cuma sebagian. Semua cuma ada di browser kamu dan ga disimpan di mana pun.
