asumsi yang dipakai
  • Mesin virtual: Linux, tenancy biasa. AWS pakai harga EC2 on-demand, GCP pakai harga Compute Engine. Seri N2 di GCP otomatis dapat sustained use discount kalau nyala lebih dari 25% sebulan, E2 tidak. Mode komitmen dihitung penuh 730 jam/bulan: AWS pakai Reserved Instance standar tanpa uang muka, GCP pakai committed use discount berbasis resource.
  • Block storage: SSD = EBS gp3 vs Persistent Disk balanced, HDD = EBS st1 vs Persistent Disk standard. IOPS dan throughput di atas baseline gp3 tidak dihitung.
  • Object storage: cuma biaya simpan per GB. Biaya request, retrieval, dan minimum durasi simpan tidak masuk. Kelas arsip: S3 Glacier Flexible Retrieval vs GCS Archive.
  • Database: RDS (MySQL atau PostgreSQL) dengan storage gp3 vs Cloud SQL Enterprise dengan SSD. HA berarti Multi-AZ di AWS dan instance regional di GCP. Backup tidak dihitung.
  • Load balancer: AWS Application Load Balancer, dengan anggapan 1 LCU-jam ≈ 1 GB data diproses. GCP dihitung dari forwarding rule (5 pertama satu harga, sisanya per rule) plus data yang diproses.
  • Egress: data keluar ke internet. AWS satu tarif ke mana pun, GCP Premium Tier tarifnya tergantung tujuan. Transfer antar-zona dan antar-region tidak dihitung.
  • Kubernetes: cuma biaya control plane EKS dan GKE (sama-sama $0,10/jam per cluster). Node-nya hitung sebagai VM di atas.

Semua hitungan jalan di browser kamu dan ga ada yang disimpan. Mau berbagi isian? Pakai salin tautan, isiannya ikut di tautan itu.
