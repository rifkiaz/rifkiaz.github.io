⚠ This is a rough estimate, not a bill. The numbers come from AWS and GCP public price lists as of , in USD, before tax, contract discounts, credits, or free tier. Cloud prices can change any time, so double-check with the official calculators before you decide anything: AWS Pricing Calculator and Google Cloud Pricing Calculator.

assumptions used
  • Virtual machines: Linux, default tenancy. AWS uses EC2 on-demand prices, GCP uses Compute Engine prices. The N2 series on GCP automatically gets a sustained use discount when it runs more than 25% of the month, E2 doesn't. Commitment modes are counted at a full 730 hours/month: AWS uses standard no-upfront Reserved Instances, GCP uses resource-based committed use discounts.
  • Block storage: SSD = EBS gp3 vs Persistent Disk balanced, HDD = EBS st1 vs Persistent Disk standard. IOPS and throughput above the gp3 baseline aren't counted.
  • Object storage: storage cost per GB only. Request, retrieval, and minimum storage duration charges aren't included. Archive class: S3 Glacier Flexible Retrieval vs GCS Archive.
  • Database: RDS (MySQL or PostgreSQL) with gp3 storage vs Cloud SQL Enterprise with SSD. HA means Multi-AZ on AWS and a regional instance on GCP. Backups aren't counted.
  • Load balancer: AWS Application Load Balancer, assuming 1 LCU-hour ≈ 1 GB of data processed. GCP is counted from forwarding rules (the first 5 at one price, the rest per rule) plus data processed.
  • Egress: data out to the internet. AWS has one rate to everywhere, GCP Premium Tier rates depend on the destination. Inter-zone and inter-region transfer isn't counted.
  • Kubernetes: EKS and GKE control plane cost only (both $0.10/hour per cluster). Count the nodes as VMs above.

All the math runs in your browser and nothing is saved. Want to share your inputs? Use copy link, the inputs travel in the link.
