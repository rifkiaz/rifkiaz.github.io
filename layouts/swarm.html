    apa itu swarm, service, task, dan routing mesh?
    • Swarm menggabungkan beberapa mesin Docker jadi satu cluster. Manager menyimpan state cluster dan memutuskan container jalan di mana. Worker cuma menjalankan container.
    • Kamu ga menjalankan container satu per satu. Kamu bikin service dan bilang "mau 3 replika". Manager memecahnya jadi task dan menyebarkannya ke node. Kalau ada task yang mati, manager bikin gantinya.
    • Routing mesh: port yang di-publish service dibuka di semua node. Request ke node mana pun diteruskan ke salah satu task yang sehat, walau task itu ada di node lain.
    • Rolling update mengganti task sedikit demi sedikit (--update-parallelism, --update-delay). Kalau task baru gagal, update berhenti (pause) atau langsung balik (rollback), tergantung --update-failure-action.
    • drain mengosongkan node buat maintenance: task-nya dipindah, dan node itu ga dapat task baru sampai di-active-kan lagi.
    • Manager pakai Raft, jadi butuh mayoritas. Produksi biasanya pakai 3 atau 5 manager supaya tahan kalau satu mati.
