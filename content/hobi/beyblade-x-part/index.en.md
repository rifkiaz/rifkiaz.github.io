This is a list of every Beyblade X part that's been released or announced, from Basic Line (BX) and Unique Line (UX) to Custom Line (CX). Ratchets and bits share one list because they work with any line. If you want to know which ones are winning a lot right now, see [The Current Beyblade X Meta](/en/hobi/beyblade-x-meta/).

The code under each name is the product the part first appeared in. BX-00, UX-00, or CX-00 means a special release (an event, a prize, or a limited set), and codes starting with G are Hasbro releases.

All images are official Takara Tomy or Hasbro renders I took from the [Beyblade Wiki](https://beyblade.fandom.com/) on Fandom. The copyright stays with them, so every image has a "Source" link to its original page. Data collected November 2, 2026.

## Blades

Blades for Basic Line and Unique Line. For UX Expand, the blade and ratchet are fused into a single part.

{{< beyblade-katalog "blade" >}}

## Custom Line (CX) parts

Custom Line blades are assembled from several parts: Lock Chip, Main Blade (or Metal Blade plus Over Blade on CX Expand), and Assist Blade.

{{< beyblade-katalog "cx" >}}

## Ratchets

The first number is the number of protrusions, the second is the height in tenths of a millimeter. Ratchets starting with M have a metal ring at the bottom, so they're heavier.
