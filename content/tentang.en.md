Hi, I'm **Rifki Affandi**. I spend most of my days on infrastructure and DevOps.

My work is mostly about looking after Linux servers, automating provisioning with Ansible, keeping databases running, and setting up monitoring so problems show up before users notice them. I also like building small internal tools that make the team's work lighter.

## What I usually work on

- **Infrastructure automation**: Ansible (roles, inventory, Vault), shell scripting, Python.
- **Databases**: MongoDB replica sets, MariaDB/MySQL.
- **Observability**: Prometheus, exporters, Grafana, alerting.
- **Platform**: Linux (openSUSE, Ubuntu, Debian), Docker, HAProxy, OPNsense, PowerDNS.
- **CI/CD and Git**: GitHub Actions, pull request based workflows.

## Open source community

Outside of work I'm active in the FLOSS community, including openSUSE and LibreOffice Indonesia, and I spoke at GNOME.Asia Summit 2022 in Kuala Lumpur about mechanical keyboards. A lot of the posts on this blog came out of tinkering with the community. The openSUSE Indonesia community ([opensuse.id](https://opensuse.id)) also runs a local repository mirror at [download.opensuse.id](https://download.opensuse.id), so users in Indonesia get faster updates. How to use it is in my [Zypper cheat sheet](/cheatsheet/zypper/#mirror-lokal-indonesia) (in Indonesian).

I'm also an **openSUSE Member**. You can see my contributions on [openSUSE Kudos](https://kudos.opensuse.org/user/Rifkiaz). The openSUSE commands I use most are collected on the [Cheat Sheet](/cheatsheet/) page (in Indonesian). If you're in Indonesia, come say hi in the community's Telegram group, [@openSUSE_ID](https://t.me/openSUSE_ID).

## About this blog

This blog is a collection of technical notes I write so I can read them again later, for myself and for anyone who runs into the same problem. The example configs are kept generic on purpose, so adjust them to your own environment before using them in production.

Most posts were first written in Indonesian. I'm translating them to English bit by bit; the ones that are done show an **EN** link at the top of the page.
